## 🚀 Projeto em destaque

### 📦 [Dispensa Digital](https://github.com/fernandesdennys/dispensa-digital)
Aplicação de controle de estoque doméstico, desenvolvida em parceria com um colega — eu no front-end, ele no back-end.

- **Front-end:** React 19 + Vite + TypeScript + Tailwind CSS 4, validação de formulários com Zod e consumo de API com Axios
- **Back-end:** Java + Spring Boot, autenticação via JWT e Spring Security, PostgreSQL em produção
- **Infra:** deploy em produção (Render), com API e banco de dados na nuvem
- Funcionalidades: dashboard, controle de despensa, lista de compras e histórico de movimentações

*Um projeto real, do design ao deploy — onde aplico o que estudo em um contexto de produto de verdade.*
